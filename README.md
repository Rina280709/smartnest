# smartnest
Учебный проект - лендинг умного дома 
Одностраничный адаптивный сайт об интеллектуальных системах для дома. Создан в рамках учебного процесса с использованием современных ИИ-инструментов.

Технологии:
- HTML5 (семантическая верстка)
- CSS3 (адаптивность, Flexbox)
- JavaScript (интерактивные элементы)
